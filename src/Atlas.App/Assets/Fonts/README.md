# Polices bundlées — Atlas.App

Polices embarquées dans le client Uno (rôles définis dans `Styles/Theme.xaml`, cf. `docs/16-polices-et-lisibilite.md`).
Seule la graisse **Regular** est bundlée ; Bold/SemiBold (titres) sont synthétisés par le moteur de rendu.
Les fichiers complets (toutes graisses) restent disponibles dans `docs/design/fonts/`.

| Fichier | Famille | Rôle (`Theme.xaml`) | Licence |
|---|---|---|---|
| `AtkinsonHyperlegible-Regular.ttf` | Atkinson Hyperlegible | `AtlasFontBody` (corps) | OFL — voir `AtkinsonHyperlegible-OFL.txt` |
| `IBMPlexSerif-Regular.ttf` | IBM Plex Serif | `AtlasFontHeading` (titres) | OFL — voir `IBMPlex-OFL.txt` |
| `IBMPlexMono-Regular.ttf` | IBM Plex Mono | `AtlasFontMono` (mono) | OFL — voir `IBMPlex-OFL.txt` |

Les polices sont sous **SIL Open Font License 1.1** : compatible avec la distribution dans un projet AGPL.
La licence accompagne les fichiers (exigence OFL) via les `*-OFL.txt` ci-joints.
